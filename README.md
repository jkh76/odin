# 오딘 카드 대전

카드 게임 오딘(Odin)의 규칙으로 컴퓨터와 대전하는 개인 연습용 웹 게임입니다. `index.html` 한 파일로 동작하고, 설치나 빌드 없이 브라우저에서 열면 바로 플레이할 수 있습니다. 휴대폰 화면에 맞춰 만들었고, 홈 화면에 추가해 앱처럼 쓸 수도 있습니다.

## 게임 설정

- 인원: 2~6명 (나 + 컴퓨터)
- 게임 종료 점수: -10 / -15 / -20점
- 다음 판 선 플레이어: 손패를 먼저 턴 사람, 또는 차례대로 돌아가며
- 프로모 카드 "심술 염소(0)" 포함 여부
- 2인 추천 규칙: 4가지 색만 사용

## 규칙 요약

- 6가지 색, 숫자 1~9 카드를 9장씩 받습니다. 손패를 먼저 비우면 그 판이 끝납니다.
- 라운드의 첫 플레이어는 1장만 냅니다. 손패 전체가 같은 색이거나 같은 숫자면 한 번에 모두 낼 수 있습니다.
- 다음 플레이어는 테이블 카드와 같은 장수 또는 1장 더 많게 내거나 패스합니다.
- 여러 장은 모두 같은 숫자이거나 모두 같은 색이어야 합니다. 큰 숫자부터 이어 붙인 수가 값이고(9와 5는 95), 테이블보다 커야 합니다.
- 카드를 내면 방금 이긴 카드 중 1장을 가져오고 나머지는 버립니다.
- 나머지 모두가 패스하면 테이블을 치우고, 마지막으로 낸 사람이 새 라운드를 시작합니다.
- 판이 끝나면 남은 손패 1장당 -1점입니다. 종료 점수에 닿는 사람이 나오면 게임이 끝나고, 감점이 가장 적은 사람이 이깁니다.
- 심술 염소(0): 어떤 색으로든 쓸 수 있는 0입니다. 같은 색 묶음에만 붙일 수 있고 항상 맨 뒤에 놓입니다(초록 2 + 염소 = 20). 판이 끝날 때 들고 있으면 -5점입니다.

## 화면과 연출

- 카드를 내면 테이블로 날아가 착지하고, 상대 카드는 뒷면에서 뒤집히며 나타납니다.
- 판이 시작되면 내 손패 칸으로 화면이 이동한 뒤 카드를 한 장씩 나눠 줍니다.
- 손패는 부채꼴로 펼쳐지고, 내 차례에는 낼 수 있는 카드만 은은하게 빛납니다. 낼 카드가 없으면 패스 버튼이 강조됩니다.
- 차례인 사람의 칸 테두리를 따라 빛이 돕니다.
- 상대 칸에는 그 상대가 가장 최근에 테이블에서 가져간 카드가 표시됩니다.
- 효과음: 카드 낼 때, 내가 이기면 빵빠레, 상대가 이기면 놀리는 음악 (소리 끄기 가능)
- 전적(승·패·승률)은 브라우저에 저장됩니다.
- 기기에서 애니메이션 줄이기 설정을 켜면 연출이 꺼집니다.

## 파일

- `index.html`: 게임 전체 (HTML, CSS, JavaScript)
- `favicon.ico`, `icons/`, `manifest.webmanifest`: 아이콘과 홈 화면 추가용 설정
- `CLAUDE.md`: 개발 메모 (코드 구조, 작업 방식)

## 안내

비공식 구현이며 원작 그림은 사용하지 않습니다. 원작 Odin은 Helvetiq에서 출판했습니다.
